# Raz Tassa

Electrical Engineering student at Tel Aviv University (B.Sc., expected 2028), focused on control and autonomous systems.
Control Lead on the drilling arm of **TAURoverIL**, the university's Mars rover team.

I write real-time C/C++ firmware and connect it to Linux/ROS 2 systems, then debug the result on real hardware.
